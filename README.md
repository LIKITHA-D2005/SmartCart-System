# 🛒 SmartCart System: Customer Segmentation using Unsupervised Learning

## 📌 Overview
This project implements an **unsupervised learning-based SmartCart system** to analyze customer behavior and segment users based on purchasing patterns.

By leveraging clustering techniques, the system helps identify distinct customer groups, enabling **personalized marketing strategies and smarter business decisions**.

---

## ⚙️ Algorithms & Techniques Used

### 🔹 K-Means Clustering
• Identifies optimal customer segments  
• Uses Elbow Method & Silhouette Score for best K selection  
• Groups customers based on spending and behavior patterns  

### 🔹 Agglomerative Clustering
• Hierarchical clustering approach  
• Provides deeper insights into customer grouping  
• Used for final segmentation and analysis  

### 🔹 Dimensionality Reduction (PCA)
• Reduces high-dimensional data into 2D/3D  
• Helps visualize clusters effectively  

---

## ✨ Features
• Data preprocessing (handling missing values, feature engineering)  
• Feature creation (Age, Total Spending, Customer Tenure)  
• One-Hot Encoding for categorical variables  
• Data scaling using StandardScaler  
• Outlier detection and removal  
• Cluster visualization (2D & 3D plots)  
• Customer segmentation insights for business decisions  

---

## 🎮 Workflow
• Load and clean customer dataset  
• Perform feature engineering (Age, Spending, Children, Tenure)  
• Encode categorical data & scale features  
• Apply PCA for visualization  
• Determine optimal clusters using Elbow & Silhouette methods  
• Perform clustering (K-Means & Agglomerative)  
• Analyze and interpret customer segments  

---

## 📊 Results & Insights
• Identified distinct customer segments based on income and spending  
• High-income customers show higher spending behavior  
• Low/moderate income groups require targeted marketing strategies  
• Clustering enables:
  - Personalized recommendations  
  - Customer retention strategies  
  - Business decision optimization  

### 🧠 Business Impact
• Cluster 0 → Discount & promotional offers  
• Cluster 1 → Loyalty programs for high-value customers  
• Other clusters → Targeted engagement strategies
